# VibeAI (Vercel)

Files at the top level: index.html, style.css, app.js, config.js, vercel.json, package.json
Folder `api`: chat.js, status.js   (this folder MUST exist in GitHub as api/chat.js and api/status.js)

Add the environment variable GROQ_API_KEY in Vercel (Settings > Environment Variables), then Redeploy.
Never put the key in any file.
